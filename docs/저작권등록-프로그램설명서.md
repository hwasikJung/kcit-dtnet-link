## 0. 표준연계키 정의

### 0.1 표준연계키란

건축물대장 데이터에는 총괄표제부 PK, 표제부 PK와 같은 건물 키가 존재하지만, 아래와 같은 경우 하나의 '장소'를 대표하는 단일 키로 사용할 수 없는 문제가 있다.

- 한 장소가 여러 주소에 걸쳐 있어 **총괄표제부가 여러 개**인 경우
- **총괄표제부에 속하지 않은 표제부**가 함께 섞여 있는 경우

즉, 총괄표제부 PK나 표제부 PK만으로는 한 장소를 대표할 수 없는 경우가 발생한다.

이를 해결하기 위해 **최상위 건물을 지칭하는 표준연계키**를 생성한다.

### 0.2 데이터 예시

**문제 상황**
한 장소가 여러 주소에 걸쳐 있어 총괄표제부가 여러 개이거나 총괄에 속하지 않은 표제부가 섞여 있는 경우, 주소 하나로 조회하면 같이 묶여야 할 건축물대장 일부가 조회 결과에서 빠지는 문제가 발생한다.

**예시: 홍은벽산아파트**

| 구분 | 내용 |
| --- | --- |
| 주소 | 홍은동 455번지 / 홍은동 455-1번지 / 세검정로1길 95 / 세검정로1길 93 |

**표준연계키 생성 전**

| 구분 | 내용 |
| --- | --- |
| 총괄표제부 | 2건 (11410-370, 11410-261) |
| 표제부 | 24건 (11410-21498 외 23건) |
| 문제점 | 홍은벽산아파트 전체를 대표할 수 있는 PK 부재 |

**표준연계키 생성 후**

| 구분 | 내용 |
| --- | --- |
| 표준연계키 | S_11410_R_11410-261 |
| 의미 | 위 표준연계키가 홍은벽산아파트 전체(총괄표제부 2건 + 표제부 24건)를 대표 |

## 1. S/W 소개

표준연계키 생성 모듈(S/W)은 도로명·지번 주소를 입력받아 해당 건축물의 **표준연계키(건축물대장 관리 건물 PK, mgmBldPk)** 를 생성·조회·변환하는 웹 기반 소프트웨어이다.

건물 단위 데이터 연계 사업에서는 서로 다른 시스템의 건물 정보를 하나로 잇기 위한 공통 식별자(표준연계키)가 필요하다. 본 프로그램은 주소 정제·매칭·지오코딩 API와 연계하여, 데이터베이스나 API에 대한 전문 지식이 없는 **비개발자도** 웹 화면에서 주소 입력만으로 표준연계키를 생성·확인할 수 있도록 하는 것을 목적으로 한다.

프로그램은 다음 세 개의 메뉴로 구성된다.

1. **표준연계키 생성** — 주소 1건을 입력하여 표준연계키를 생성하고 상세 정보를 확인하는 화면
2. **표준연계키 일괄처리** — 엑셀 파일 또는 붙여넣기 데이터로 다수의 주소·키를 한 번에 처리하는 화면
3. **전체 기능** — 연계 API의 모든 기능을 파라미터 폼으로 직접 실행하는 전문가용 콘솔 화면

## 2. 특장점

1. 비개발자 중심의 자동화 파이프라인
주소 한 줄만 입력하면 주소 정제 → 건축물대장 매칭 → 표준연계키 생성의 3단계 과정을 자동으로 수행하고, 각 단계의 진행 상태를 시각적으로 표시한다.
API 호출 방법이나 응답 구조를 몰라도 결과 키 카드에서 표준연계키와 총괄표제부·표제부 PK를 바로 복사해 사용할 수 있다.

2. 입력 형식 자동 감지
입력창에 들어온 값이 주소인지, 구형 건축물대장 PK(예: 11680-12777)인지, 신형 건축물대장 PK(예: 11151100324757 — 자릿수 가변)인지, 표준연계키(R_/T_/S_ 접두)인지를 자동으로 판별하여 각 형식에 맞는 기능(키 생성, 대장 정보 조회, 신·구 PK 전환, 표준연계키 조회)을 제시한다.
사용자가 기능을 찾아다닐 필요가 없다.

3. 대량 일괄처리와 안정적 작업 제어
엑셀 업로드 또는 표 붙여넣기로 최대 5,000행을 일괄 처리한다(실측 기준 5,000행 조회에 약 1.5분).
동시 5건의 병렬 처리(워커 풀), 진행 중 중단(진행분 보존), 실패 행만 선별 재시도, 상태별 필터, 결과 엑셀 다운로드를 지원한다. 결과 파일은 업로드 파일의 열 구성(A열 입력값과 B열 이후의 원본 데이터)을 그대로 유지한 채 원본 마지막 열 뒤에 조회 결과 컬럼을 덧붙인 형태라, 후처리 없이 원본 대장에 결과가 결합된 파일을 바로 얻는다.

4. 서버 저장 없는 개인정보 친화 구조
처리 결과와 이력은 서버가 아닌 사용자 브라우저(localStorage, IndexedDB)에만 저장된다. PC 간 이동·공유는 이력 JSON 내보내기·가져오기 기능으로 처리한다.

5. 결과의 재현과 공유
생성 결과는 URL 공유 링크(`?addr=주소`)로 전달할 수 있어 수신자가 링크를 열면 동일한 결과가 자동 재생성된다.
위치 좌표(WGS84 위도·경도)는 접이식 미니 지도로 즉시 검증할 수 있다.

6. 이중 사용자층 지원
일반 사용자용 안내형 화면(메뉴 1·2)과 전문가용 콘솔(메뉴 3)을 한 프로그램 안에 제공한다.
전문가 콘솔은 연계 API 스펙을 빌드 시점에 스냅샷하여 태그별 기능 목록·검색·동적 파라미터 폼·JSON 결과 뷰어를 제공한다.

7. 무거운 설치 없는 표준 배포
정적 SPA로 빌드되어 WAR 패키지 형태로 표준 WAS(Tomcat 등)에 그대로 배포되며, 서버 런타임 의존성이 없다. 클립보드 복사 등 브라우저 기능은 HTTPS가 아닌 HTTP 배포 환경에서도 동작하도록 폴백을 갖추었다.

## 3. 주요기능

1. 표준연계키 생성(메뉴 1)
- 주소 입력 시 정제·매칭·키 생성 3단계 파이프라인을 자동 수행하고 단계별 진행 상태 표시
- 주소 정제, 건축물대장 매칭, 위치 좌표 조회의 3개 연계 기능 병렬 호출로 응답 시간 단축
- 결과 키 카드: 표준연계키(R_/T_/S_)·총괄표제부 PK·표제부 PK 표시, 개별 복사·요약 복사·공유 링크 복사
- 매칭 등급(M1/M2/M3) 설명 툴팁 제공
- 표제부 동 정보(동명, 주/부속 구분, 소속 총괄) 자동 조회 — 총괄표제부가 여러 건이면 총괄별 접이식 그룹으로 표시
- 위치 좌표(WGS84 위도·경도) 행과 접이식 미니 지도(OSM 타일, 오프라인 시 외부 지도 링크 폴백)
- 동일 주소가 여러 지역에 매칭되는 경우(다지역) 후보 목록 제시
- 주소 입력 중 실시간 자동완성(디바운스 적용)
- 대장 정보 조회 모달: 생성된 PK의 건축물대장 기본 정보·표제부 정보를 페이지 이동 없이 확인
- 신·구 PK 전환 모달: 구형 PK를 신형 PK로 변환
- PK·표준연계키 직접 입력 감지: 입력창에 구형·신형 PK 또는 표준연계키(R_/T_/S_)를 넣으면 생성 대신 조회·전환 액션 패널을 표시하고, 표준연계키와 소속 건물 목록(대장 종류·기존/신규 PK·건물명·주소)을 자동 조회
- 공유 링크(`?addr=주소`) 진입 시 자동 생성
- 최근 생성 이력 10건 저장(브라우저 localStorage), 클릭 시 자동 재생성

2. 표준연계키 일괄처리(메뉴 2)
- 주소기반 일괄처리 : 엑셀 A열의 주소 목록으로 표준연계키 일괄 생성. 총괄표제부 PK가 비어 있는 행은 표제부 PK로 후속 조회하여 자동 보강
- PK기반 일괄처리 : A열의 표준연계키(R_/T_/S_ 접두) 또는 구형·신형 대장 PK로 표준연계키 정보 일괄 조회. 입력 형식에 맞는 조회 파라미터 자동 선택
- 엑셀 파일 업로드(.xlsx) 및 파일 없이 표 붙여넣기 입력(탭 구분 열 보존)
- 최대 5,000행, 동시 5건 병렬 처리(워커 풀), 진행률 표시
- 처리 중단 버튼: 진행분은 저장하고 미처리 행은 대기 상태로 유지
- 결과 테이블: 상태 요약 칩(성공/실패 등) 클릭 필터, 행 클릭 상세 모달
- 상세 모달: 총괄표제부 행이면 소속 표제부 목록을 접이식으로 지연 조회, 표제부 행 클릭 시 대장 정보 인라인 확장(PK별 캐시)
- 실패 행 일괄 재시도
- 결과 엑셀 다운로드 — 업로드 파일의 열 구성(A열 입력값 + B열 이후 원본 데이터)을 그대로 두고 원본 마지막 열 뒤에 조회 결과 컬럼·상태를 추가
- 처리 이력: 브라우저 IndexedDB에 최근 20건 저장, 이력 JSON 내보내기·가져오기

3. 전체 기능(메뉴 3)
- 연계 API 기능 24개를 태그별 목록·검색으로 탐색(빌드 시점 스펙 스냅샷 27개 엔드포인트 중 내부용 제외 24개 노출)
- 기능별 동적 파라미터 입력 폼 자동 생성
- 실행 결과를 JSON 뷰어로 표시
- URL 쿼리(`?path=기능경로&파라미터=값&run=1`)로 프리필·자동 실행 — 다른 화면에서의 연계 진입 지원
- 최근 호출 이력 20건 저장(브라우저 localStorage)

4. 공통 기능
- 연계 서버 연결 상태 표시: 헤더의 상태 점이 60초 주기로 서버 도달 여부를 점검, 클릭 시 즉시 재확인
- 클립보드 복사 폴백: 보안 컨텍스트(HTTPS)가 아닌 HTTP 배포 환경에서도 복사 버튼 정상 동작
- 한국어 단일 UI, 반응형 레이아웃

## 4. 사용방법

1. 실행
배포된 URL에 웹 브라우저로 접속한다. 별도의 로그인·설치 과정은 없다.

2. 표준연계키 생성 (메뉴 1)
STEP 1. 초기 화면의 입력창에 조회할 주소(도로명 또는 지번)를 입력한다. 입력 중 나타나는 자동완성 후보를 선택할 수도 있다.
STEP 2. 생성 버튼을 누르면 정제 → 매칭 → 생성 3단계가 자동 진행되고, 완료되면 결과 키 카드가 표시된다.
STEP 3. 키 카드에서 표준연계키와 총괄표제부 PK·표제부 PK를 복사 버튼으로 복사한다. 요약 복사·공유 링크 복사도 가능하다.
STEP 4. 위치 행에서 위경도 좌표를 확인하고, 펼치면 미니 지도로 위치를 검증할 수 있다.
STEP 5. 대장 정보 버튼을 누르면 건축물대장 정보가 모달로 표시되고, 신규 PK 전환 버튼으로 구형 PK를 신형 PK로 변환할 수 있다.
STEP 6. 입력창에 주소 대신 총괄표제부 PK·표제부 PK(구형·신형) 또는 표준연계키(R_/T_/S_)를 직접 입력하면 해당 값에 대한 조회·전환 액션 패널과 소속 건물 목록이 표시된다.
STEP 7. 화면 하단의 최근 생성 이력을 클릭하면 해당 주소로 즉시 재생성된다.

3. 표준연계키 일괄처리 (메뉴 2)
STEP 1. 처리 종류에 맞는 탭(주소기반 / PK기반)을 선택한다.
STEP 2. A열에 주소(또는 키·PK)가 들어 있는 엑셀 파일을 업로드하거나, 엑셀에서 복사한 표를 붙여넣는다. B열 이후에 다른 데이터가 있어도 그대로 유지되며, 조회 결과는 원본 마지막 열 뒤에 새 컬럼으로 추가된다.
STEP 3. 처리 시작 버튼을 누르면 진행률과 함께 일괄 처리가 진행된다. 필요 시 중단 버튼으로 멈출 수 있으며 진행분은 보존된다.
STEP 4. 완료 후 상태 요약 칩으로 성공·실패 행을 필터링하고, 행을 클릭하면 상세 정보를 모달로 확인한다. 실패 행은 재시도 버튼으로 다시 처리한다.
STEP 5. 결과 다운로드 버튼으로 원본 컬럼이 보존된 결과 엑셀 파일을 저장한다.
STEP 6. 처리 결과는 이력에 자동 저장되며(최근 20건), 이력 내보내기·가져오기로 다른 PC와 공유할 수 있다.

4. 전체 기능 (메뉴 3)
STEP 1. 좌측 목록에서 태그별 기능을 탐색하거나 검색어로 기능을 찾는다.
STEP 2. 기능을 선택하면 파라미터 입력 폼이 표시된다. 필요한 값을 입력한다.
STEP 3. 실행 버튼을 누르면 결과가 JSON 뷰어로 표시된다.
STEP 4. 최근 호출 이력에서 이전 호출을 선택해 동일 조건으로 재실행할 수 있다.
